Cleanup Web Scanner

Pemindai cache & pembersih aman — hanya folder terdaftar, selalu didahului pratinjau dan konfirmasi.

Panduan Hapus Aman

Penghapusan dilakukan manual lewat File Explorer. Aplikasi ini hanya menampilkan ringkasan dan tidak menyediakan tombol pintas apa pun.

Bersihkan Cache & File Sementara

Hanya folder yang terdaftar di bawah ini yang boleh dibersihkan. Anda tidak dapat memasukkan path sendiri. File yang lebih baru dari 24 jam selalu dilewati, begitu pula cookie, riwayat, dan sandi browser.

  • Pratinjau dulu — lihat berapa file dan byte yang akan dihapus sebelum memutuskan.
  • Anda harus mencentang konfirmasi sebelum penghapusan dapat dimulai.
  • Folder akar tidak pernah dihapus, hanya isinya. File yang sedang dipakai akan dilewati.
